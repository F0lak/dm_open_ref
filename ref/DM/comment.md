
## comment (info)
***
Comments may be used to explain code. They can also be used to turn off a line or block of code. All text inside a comment is ignored by the compiler.

The single line comment begins with <code>//</code> and runs to the end of the line.

The multi-line comment begins with <code>/*</code> and runs until <code>*/</code>.

Multi-line comments may be nested.


```dm

  // single line comment
  /*
     multi-line comment
  */

```
