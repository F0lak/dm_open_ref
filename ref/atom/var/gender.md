
## gender (var)

**Default Value:**
+   "neuter"
***
This sets the object's gender. This influences text macros like <code>\he</code>, which may expand to "it", "he", "she", or "they". Valid values are:


```dm

"neuter"
"male"
"female"
"plural"

```



```dm

NEUTER
MALE
FEMALE
PLURAL

```
