
## IconStates (proc)

**Format:**
+   IconStates(mode=0)

**Arguments:**
+   mode: see [icon_states proc](/ref/proc/icon_states)
***
This returns a list of all icon state text strings that exist in the /icon object. This works in exactly the same way as icon_states(icon).
