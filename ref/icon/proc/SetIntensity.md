
## SetIntensity (proc)

**Format:**
+   SetIntensity(r,g=r,b=r)

**Arguments:**
+   r: red component
+   g: green component
+   b: blue component
***
This multiplies the pixel intensities by the specified amounts. A value greater than 1.0 increases the intensity and a value less than 1.0 decreases the intensity.
