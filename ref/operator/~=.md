
## ~= (info)

**Format:**
+   A ~= B

**Returns:**
+   1 if A and B are equivalent; 0 otherwise
***
Equivalence is a looser version of equality:

To check if A and B are equal, use the == operator.

Note: For code compiled in version 516 or later, <a href="#/list/associations">associated values</a> in lists are also checked for equality. This was not the case for older versions.
