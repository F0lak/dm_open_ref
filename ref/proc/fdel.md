
## fdel (proc)

**Format:**
+   fdel(File)

**Arguments:**
+   File: name of file to delete

**Returns:**
+   1 on success; 0 otherwise.
***
If the specified file ends in '<code>/</code>', it is treated as a directory. Any contents (including sub-directories) are deleted as well.

Be careful!
