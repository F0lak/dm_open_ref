
## ftime (proc)

**Format:**
+   ftime(File, IsCreationTime)

**Arguments:**
+   File: name of file to test
+   IsCreationTime (optional): true to return file creation time, false (default) to return last-modified time

**Returns:**
+   A time value that can be sent to time2text().
