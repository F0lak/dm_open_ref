
## islist (proc)

**Format:**
+   islist(Object)

**Arguments:**
+   Object: The value to test

**Returns:**
+   1 if the object is a valid list; 0 otherwise.
***
Tests whether an object is a list. This includes user-defined lists, special lists like `contents` and `overlays`, and more.
