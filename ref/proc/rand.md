
## rand (proc)

**Format:**
+   rand(L=0,H) or rand()

**Arguments:**
+   L: A number for the lower-bound.
+   H: A number for the upper-bound.

**Returns:**
+   A random integer between L and H inclusive; or a random number from 0 up
to 1 if L and H are omitted.
