
## sin (proc)

**Format:**
+   sin(X)

**Returns:**
+   The sine of X, where X is in degrees.
***

```dm

mob/verb/test()
   usr << sin(0)  // 0
   usr << sin(45) // 0.707...
   usr << sin(90) // 1

```
