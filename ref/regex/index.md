
## regex (info)
***
The /regex datum holds a regular expression that can be used for searching and/or replacing text. Rather than searching for a specific piece of text, a regular expression is a *pattern* to search for. This can include things like wildcards. See <a href="#/{notes}/regex">Regular expressions</a> for more information.

A new regular expression can be created with regex() or new/regex().
