
## popup_menu (info)

**Format:**
+   set popup_menu = Setting

**Arguments:**
+   Setting: 1 (default) for showing this verb in the popup menus; 0 otherwise.
***
Use this to prevent a verb from showing up in the popup "context" menu when users right-click on objects.
